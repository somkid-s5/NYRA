# Architecture diagrams

No architecture diagrams have been generated yet. The project owner requires the **Diagram Design Skill** for professional diagrams in Markdown architecture/system/data-flow documentation, but that skill was **not available** to the session that prepared this planning repository.

Before producing architecture diagrams:
- install or expose the exact Diagram Design Skill;
- prepare professional component, execution/data-flow and workflow diagrams;
- store rendered image files in this directory with relative links in docs/architecture.md;
- preserve editable source if the tool supports it;
- verify referenced files exist and GitHub previews render.

Do not fill this directory with quick ASCII art or throwaway Mermaid pretending to satisfy this requirement.
