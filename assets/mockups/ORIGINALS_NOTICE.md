# Source clarification for NYRA TUI mockups

The first four mockup images from the design conversation were **original PNG screenshots generated in chat**. They are **not stored in this GitHub repository** as of this note.

This repository has four editable SVG mockups and a GitHub Actions workflow that rasterizes these SVGs to PNG, plus a 2x2 comparison sheet. These rendered PNGs are **faithful exports of the repository SVGs**, not byte-for-byte copies of the original chat-generated images. They are reference design mockups, not screenshots of a running NYRA application.

If the exact original chat PNGs are desired in the Git repository, upload the four originals manually to `assets/mockups/originals/` from the ZIP generated in chat. Use these filenames:

- `nyra-original-cyber-cyan.png`
- `nyra-original-crimson-noir.png`
- `nyra-original-neo-tokyo.png`
- `nyra-original-acid-grid.png`

See the user's ZIP download link in the originating ChatGPT conversation. Do not rename re-rendered PNGs to imply they are those originals.
